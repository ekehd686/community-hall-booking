# Community Hall Booking & Management System

A beginner-friendly Flask prototype for VTU Community/Societal Project Topic 78.

## Features
- Home page and hall listing
- Hall availability checking
- Booking request form
- Booking status/history
- Admin dashboard
- Approve/reject booking requests
- Maintenance scheduling
- Simple booking conflict prevention

## Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: `pip install flask`
4. Run: `python app.py`
5. Open the address shown in the terminal (normally http://127.0.0.1:5000).

This demo uses in-memory data for simplicity. For the final project, replace the lists in app.py with MySQL tables.
